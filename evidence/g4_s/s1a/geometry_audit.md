# G4-S1A 几何与物理夹持前置门禁

本附录对应 `geometry_audit.json` 与 `scripts/g4s1a_geometry_audit.py`。审阅前的本任务证据另存 `geometry_audit_pre_review.json`，保留原始采集结果；独立审阅后修正自定义浮点半径入口转有理数，默认分数半径的原证据数值不变。
结论为 **原 Factory 忠实碰撞重建尚未完成；不得开始原任务物理/策略实验**。
对合法、独立数学诊断的正结果不构成 Factory 资产转换通过。

仅在本地以已有 USD 0.22.11 解析，读取其原三角索引面和点，在内存中计算标量、拓扑与
严格有理数几何界。没有输出原顶点、原面索引、USD、STL/OBJ、衍生 MJCF 或 cooked
buffer。peg/hole 原 SHA-256 与 S0 一致，读取后再次相同。全原资产许可由独立许可矩阵
决定；没有把“能读”当作“允许转换/公开分发”。原几何保持不变，没有调整孔或 peg。

参考身份如下；远端来源关联沿用 S0 证据边界，不新声称远端正文 SHA 已核验。

## 配置的 57 µm 与原始 mesh 并不相同

冻结 `factory_tasks_cfg.py` 规定 peg 直径 .007986 m、hole 直径 .0081 m，得到名义径向
差 **57 µm**。这只是配置值；不会把 USD 真实孔径设成这个数。源码的 USD spawn
没有借该 diameter 字段缩放碰撞几何。

本次得到一个必须在后续重建前解决的差异：原 hole **直孔段 mesh 内壁半径约4.5 mm**，
不是配置推算的4.05 mm。以下是所有三角面与所列精确 z 平面相交所得折线的**整段**
径向极值；不是只量顶点或只取有限角度。显示平方根为近似小数，JSON 保留精确平方
分数，可以用整数平方比较复核。

| 原 raw mesh 截面 | z，m | 最小半径，mm | 最大半径，mm |
|---|---:|---:|---:|
| peg 直段 | .001 / .025 / .049 | 3.992046726 | 3.993004597 |
| hole 直孔 | .001 / .0125 / .0239 | 4.498925657 | 4.500004881 |
| hole 顶口倒角 | .0245 | 4.998806496 | 5.000004957 |

这几个 z 截面本身并非全表面证明。为避免将截面采样升级为全段证书，另外对**全部588
个与开区间 `0<z<.024000000208616257` 相交的原三角面**做精确有理数 slab clipping。
每个被裁剪凸多边形投影到 XY，检查原点是否在其内部，并计算每条边上完整二次范数
的极小值；以所有三角面/内部的最小值得到整个 raw 边界 slab 的半径下界。此计算不
按径向阈值排除面，也覆盖浮点点位微差导致的非竖直小三角面。

结合完整 raw peg 所有原点的最大径向范数（范数凸性给出其全部三角面的上界），采用
精确整数平方根构造1e-15 m 网格上的向外平方根夹界，得到：

- 整个 raw 直孔 slab 边界径向下界：**.004498925657431 m**；
- 完整 raw peg 最大半径上界：**.003993004597001 m**；
- 二者共轴、竖直放置的 raw 几何径向间隙下界：**.000505921060430 m**，即
  **505.921060430 µm，约名义57 µm的8.8758倍**。

范围仅为原 raw mesh 的该直孔 slab 与共轴几何容纳；不涵盖任意姿态、插入到孔底、
接触 offset、夹持、动力学或 cooked SDF。不得通过缩放“修正”到57 µm，也不得说
实际训练孔的有效碰撞间隙已经测成505.9 µm。

原 mesh 经**精确坐标去重**后均无边界边、非流形边、零面积面或边朝向不一致；peg
去重后578点/1728边，Euler=2；hole1897点/5709边，Euler=-6。不能凭“封闭流形”
推出形状等于理想圆柱或理想 annulus。精确轴线/原三角面相交仅在 hole 的
`z=-.003000000026077032` 与 `z=0` 出现；轴线高于AABB的起点属于外部，且向下到正z孔段无面交点；结合闭合定向表面，轴点属于孔腔外部空间。与全slab径向界结合，只支持该段的共轴径向空隙，不声称完整peg跨越孔底仍容纳。轴面交点表明中心存在孔底/下部底座，正 z
孔腔不能被替换成无底贯通圆环。与轴平行且投影包含轴的三角面会显式报歧义，不能
通过跳过零投影面积面而漏掉轴面。

原 USD 的 cooked convexHull/triangleMesh buffer 仍未解码，源 `sdf` 的运行时
有效零等值面没有在 PhysX 中探测。因此以下全部仍为 **UNKNOWN**：

1. 原 raw mesh 与源 cooked PhysX SDF 的表面偏差；
2. 原几何到拟转换网格的 Hausdorff 误差（未实施转换）；
3. 原 cooked SDF 到 MuJoCo 碰撞面的最终误差；
4. 能否在57 µm名义尺度上建立原任务跨引擎的有效间隙/碰撞一致性。

“不转换所以误差为0”不是这里的结论。

## 候选碰撞表示比较

[MuJoCo 3.5 XML mesh 文档](https://mujoco.readthedocs.io/en/3.5.0/XMLreference.html#asset-mesh)
与[碰撞算法文档](https://mujoco.readthedocs.io/en/3.5.0/computation/index.html#collision-detection)
规定普通 mesh collider 采用凸表示。即使视觉面保留孔，单 mesh 的普通碰撞凸包也会
填孔。实际负控见下节，不能用这个方案作为 Factory hole。

| 表示 | 本次状态 | 必需的正确性条件 |
|---|---|---|
| 整孔一个凸包 | REJECTED | 会填实孔；不能用 |
| 三角可视 mesh 直接用普通 mesh collider | REJECTED | 保留视觉面不代表保留非凸碰撞 |
| 保孔凸分解/多块凸体 | CONDITIONAL / 未转换 | 原 inner wall、倒角、孔底、外支撑都须保留；源表面全域误差界与编译后 hull 检查；块接缝接触差异单独登记 |
| 自定义 MuJoCo SDF plugin | CONDITIONAL / 未实现 | 有权取得原形状；signed distance/gradient、拟合/插值误差及 solver 精度证据；不能直接将 PhysX cooked 字节当作可移植 SDF |
| 理想 peg/理想圆孔替换 | REJECTED 作为原任务替代 | raw/source/config 已有可测差异，且会遗漏倒角/底座；仅可独立诊断 |

[MuJoCo 3.5 SDF 扩展接口](https://mujoco.readthedocs.io/en/3.5.0/programming/extension.html#sdf)
提供可扩展接口，存在 API 不是已有原形状转换或接触一致性的证明。

## 独立数学诊断：可量化的保孔凸块

为测试目标引擎的表示能力，代码从独立数学公式生成一个**非 Factory**圆环：
`rin=.00405 m, rout=.02 m, h=.025 m`，仅借名义标量作尺度诊断，没有读取原 USD
顶点来生成它。该数学模型没有原孔底、倒角或侧部结构，绝不作为原任务模型。
源代码与原创生成公式随本仓库代码许可发布；不包含任何原 Factory 资产。

使用 N 个凸梯形棱柱：内正N边形内接圆、外正N边形外切圆。理想连续数学实体上，
这种并集包含真实 annulus 的全部材料，既不放大孔、也不缩小外实体，并保留正半径
孔腔。完整实体 Hausdorff 上界是内侧侵入与外侧多余材料的较大值；不是角度采样估计。

令 `a=(22/(7N))²/2`，利用 `π<22/7`、`1−cos x≤x²/2` 与
`sec x−1≤a/(1−a)`：

- 内侧侵入 `rin*(1−cos(π/N)) ≤ rin*a`；
- 外侧 excess `rout*(sec(π/N)−1) ≤ rout*a/(1−a)`。

JSON 对上下界保留精确分数。以下µm数值为显示近似。

| N | 内孔误差上界，µm | 外边界误差上界，µm | 名义径向剩余间隙下界，µm |
|---:|---:|---:|---:|
|16|78.133|393.432|−21.133|
|32|19.533|96.928|37.467|
|64|4.883|24.144|52.117|
|128|1.221|6.031|55.779|
|256|.3052|1.5073|56.6948|
|512|.07630|.37681|56.92370|
|1024|.01908|.09420|56.98092|

N=16 已不能保证57 µm的名义间隙不被吃掉。这个独立结果说明分解分辨率必须进入
误差预算；**不证明任何原 Factory 分解已满足这些数值**。

已有 MuJoCo3.5.0 在独立环境中实际编译 N=64 原创模型两次，64个 mesh、65个geom，
两次关键编译几何数组 SHA-256 都为
`92af208595544e148f9d3734a7fae4adb2f4c1663084232de0933c078b86657c`。
编译后的 mesh vertices 为float32；经编译器 recenter/rotation 还原并与全部原输入
顶点双向最近距离比较，最大约 **.999366 nm**。这是全部64块的浮点测量，不是向外
舍入误差证明；没有把理想解析界直接授予浮点编译 hull，更不是原资产转换误差。

在上述独立 mesh 完整性检查通过后，仅做 `mj_forward`/`mj_geomDistance` **静态**
检查，没有 `mj_step`，time 始终0，没有策略。半径.1 mm的独立球位于孔轴z=.0125：

- 保孔64块：0接触，最近距离约.003945121274 m；
- 球移到x=.00404：2接触，距离约−.000090011985 m；
- 同一独立圆环顶点改为普通单mesh collider：轴心出现1接触，距离约−.012599999924 m，
  显式拒绝为保孔模型。

这是真实引擎负控，独立于“函数输出等于自身输出”的断言。另保留3项真实编译拒绝：
零半径球、缺失 mesh、共面退化 mesh 的原始 MuJoCo/Qhull 错误。没有通过扰动、放大、
缩小或忽略错误让非法资产通过。

## 夹手、持 peg 与支撑几何

原 Panda hand collider 是600点/200面凸包；每个原 finger collider 为4245点/8202面，
声明 `convexHull`。本次未重建/导出。原finger authored bounds等完整标量见JSON。
Menagerie Panda 则有finger_0 mesh和每指5个人工box pads，不能凭相同Panda名字推断
原指尖接触面相同。原每指质量约.0297 kg，候选.015 kg；质量/惯量细项见robot映射。

必要条件仍未满足：原接触表面在各link frame的对应、凸包实际支持面、材料/摩擦/接触
参数对应、mimic双坐标与原implicit PD（7500/173、40N、joint friction .1）饱和。
peg必须是独立6DOF刚体，靠真实finger/peg接触夹持；**没有创建hand weld**。
原reset接触闭合.25s，peg相对手的随机位置与约.032392m偏置必须保留。把peg固定到手、
替换指垫或调孔大小都不是允许的补救。

桌面仅有S0顶层USD依赖证据，外部table.usd本体、碰撞几何和适用许可仍未闭合。
原hole本身为fixed-world joint，但这不证明桌面可被任意plane替代。没有构建新的
原任务支撑碰撞体，也没有启动原任务物理探针。

极小值、投影三角形内部原点、精确平方根夹界、无效分解数、理想误差预算、原始证据
身份、源配置差异、实际引擎静态正/负控与真实非法编译拒绝。全仓回归由主报告登记。

```bash
python3 scripts/g4s1a_geometry_audit.py --output /tmp/g4s1a_geometry_fresh.json
```

退出码、stderr、运行耗时、生命周期 `ru_maxrss`；RSS不是本任务增量内存。原mesh审计约
1.5s，独立模型编译/静态探针约.4s进程墙时；逐次实际数值以JSON为准。原始来源身份与
脚本SHA也一并记录。没有PPO inference、rollout、checkpoint load、训练或历史改写。

后续S1B当前应为 **NO-GO（忠实原任务模型）**：许可/原转换、raw-vs-cooked有效孔径、
